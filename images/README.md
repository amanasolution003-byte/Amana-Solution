# images/

Placez ici les visuels du site vitrine Amana-Solution.

- `logo.svg` — votre logo définitif (optionnel, voir `../README.md` rubrique « Logo »).
  Le site fonctionne déjà sans logo : un logotype texte + un symbole SVG intégrés sont utilisés par défaut.

Formats conseillés : SVG (logo), WebP ou PNG (photos écran 800×600 max par image, bien compressées).
